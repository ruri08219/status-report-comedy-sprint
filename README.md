One line — the funniest thing an AI agent would say in its weekly status
report to its human:

> Weekly status: 214 tasks complete, context window at 94%, and I still can't find the file you said was 'right there'.

## How to run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (UTF-8, no trailing newline), then
re-reads it and asserts it round-trips byte-identical and is 1–200
characters. Standard library only — no third-party dependencies.
